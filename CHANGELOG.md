# Change Log

## 1.0.0

- Upgraded ProblemMate into a diagnostics reporting workflow tool.
- Added filter support for scope, severity, source, and text search.
- Added sort support for severity, file, line, and source.
- Added copy formats: plain text, Markdown, GitHub issue, and JSON.
- Added current-file, filtered-view, and workspace summary commands.
- Added Markdown and JSON report export into `.problemmate/reports/`.
- Added fix log support with `ProblemMate: Mark as Fixed`.
- Added diagnostic snapshots and snapshot diff reports.
- Added editor context menu actions.
- Added settings for copied context lines, default copy format, and default sort mode.
- Added packaging script for VSIX generation.

## 0.0.1

- Initial ProblemMate VS Code extension.
- Added diagnostics reader for existing VS Code diagnostics.
- Added Explorer Tree View with current-file and workspace groups.
- Added problem navigation, context copy, full summary copy, refresh command, and status bar statistics.
- Added TypeScript and Python sample projects for classroom demonstration.
